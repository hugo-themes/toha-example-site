03 — Publications

2025 · Advanced Information Networking and Applications (AINA 2025), Springer · DOI 10.1007/978-3-031-87781-0_21

Dynamic User Profiling for Personalized Tourism Recommendations Using Reinforcement Learning Models ↗

Ferrario, T., Fersini, E., Messina, E., Sormani, G.

Proposes two reinforcement learning models for dynamic user profiling, a Hierarchical RL model with Matrix Factorization and a Double Deep Q-Network, to improve Point of Interest recommendations as users' interests change. The HRL model works well for users with extensive interaction histories, while the DDQN model suits new or less active users.
