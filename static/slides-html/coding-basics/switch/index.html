用白話文秒懂 Switch 核心概念

在程式世界裡，除了常見的 `if-else`（如果/否則），`switch` 是專門應對「多向選擇」的精準開關！

傳統模式：If - Else If

「逐一問話關卡」

像逐一問哨兵：「你是蘋果嗎？」不是的話才走去問下一個哨兵：「你是香蕉嗎？」選項多時較費時。

if (是蘋果嗎?) { 送蘋果區 }
else if (是香蕉嗎?) { 送香蕉區 }
Switch 模式：自動軌道分揀機

「直接轉接對應號碼」

給中央控制器物品名稱，機器直接把鐵軌轉接到對應軌道，一步到位！

switch (物品標籤) {
case "蘋果": 送蘋果區; break;
}

Switch 家族四大核心元件

1. switch (目標)

放入你要比對的物品或狀態變數。

2. case "數值":

預期的可能性。若吻合就執行該軌道的指令。

3. break;

煞車閘門！告訴程式「任務完成，跳出 switch」。

4. default:

當全部 case 都不符合時的備用招領箱。
