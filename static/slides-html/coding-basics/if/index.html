初學者學習筆記

`if` 就像是安全檢查哨。當括號裡面的條件算出為 **True（真）** 時，門才會開啟並執行裡面的程式碼！

徹底弄懂 If 條件判斷的 4 大核心法則

透過日常生活中的「安檢分流」與「邏輯問答」，一分鐘掌握程式如何做決策。

1

if ( 條件問答 ) 單向檢查

最基本的判斷：「如果條件成立（True），就執行對應動作」。條件不成立（False），電腦會直接無視該區塊。

2

else if ( 備案條件 ) 梯次銜接

「如果不符合上方條件，那檢查這個看看？」。只要上面已有條件成立，後續 `else if` 將完全被跳過！

3

else { 預設兜底 } 最後防線

「如果前面所有條件全都不符合，那就做這件事」。`else` 不用加條件，永遠放在整個判斷鏈的最末端。

4

多個 if vs if...else if 初學者陷阱

• 獨立 `if`：每一個都檢查，可能同時觸發多個結果。
• `if...else if` 鏈：具有互斥性，一個成立就立刻跳出鏈條。

雙重條件的組合工具（邏輯運算子）

&& (AND 並且)

兩邊條件都為真才是 True！

|| (OR 或者)

其中一個條件為真就是 True！

! (NOT 反轉)

將真變假、假變真！
