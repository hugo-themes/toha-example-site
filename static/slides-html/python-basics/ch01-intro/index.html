第 1 章：標準輸出機制與 print() 函式規格

1.1 print() 函式簽名與參數規格

在 Python 直譯器中，print() 是核心的內建輸出函式，負責將傳入之物件序列序列化為字元資料流，並寫入標準輸出串流（sys.stdout）。 

print(*objects, sep=' ', end='\n', file=None, flush=False)
參數名稱 預設值 型態約束 直譯器底層行為與職責說明
*objects 無（可變長度） 任意物件序列 接收零個或多個欲輸出的物件。直譯器會依序呼叫各物件之文字轉換協定。
sep ' '（單一空格） str 或 None 分隔字元（Separator）。當輸出多個物件時，直譯器在相鄰物件輸出流之間主動注入此字串。
end '\n'（換行字元） str 或 None 行尾終結符號（End）。直譯器完成所有物件輸出後，最後附加寫入標準輸出的字串。
file None 檔案物件 指定輸出目標資料流，預設為系統終端機標準輸出 sys.stdout。
flush False bool 是否強制清空輸出緩衝區（Buffer）。若為 True，直譯器立即將緩衝資料推入終端。

1.2 字面常值輸出與轉義字元

純字串常值以成對的單引號（'...'）或雙引號（"..."）界定。當字串內部包含特殊控制字元時，需使用反斜線（\）進行轉義：

  • \n（Newline）：強制換行，將標準輸出游標移至下一列開頭。
  • \t（Horizontal Tab）：水平跳格，將游標對齊至下一組定位點（預設多為 4 或 8 個字元寬度）。
  • \\ 與 \"：印出反斜線與引號本身，避免解析器提早截斷字串常值。

1.3 終端機 stdout 緩衝區與換行控制

初學者常見之誤區在於將「多個引數」與「多個 print() 呼叫」混淆。連續兩次呼叫 print() 之所以自動分成兩列，完全是由預設之 end='\n' 所驅動；若覆寫 end=""，游標便會駐留在同一列尾端。 

print("System", "Online", sep="-")
print("Loading", end="...")
print("Ready")

異常現象與錯誤訊息 引發錯誤之程式碼 直譯器底層根因分析 標準防範與修復方案

第 2 章：變數機制、符號表與賦值運算

2.1 變數本質：識別碼（Identifier）與物件繫結

在 Python 的記憶體架構中，變數絕對不是裝載資料的實體置物盒子。Python 變數的本質是「可隨時撕拔掛上的磁吸名牌（Name Tag）」，透過記憶體位址（指標）繫結至存在於堆積記憶體（Heap Memory）實體槽位中的物件。

核心心智模型：常值輸出 vs 識別碼取值
當直譯器執行 print("status") 時，雙引號告知直譯器這是一個純文字常值，直接傳入標準輸出管道；
當執行 print(status) 時，無引號告知直譯器這是一個「變數識別碼」，直譯器必須主動查詢「符號表（Symbol Table）」，順著位址指標找到對應記憶體格位中的字串內容，再提取送入終端機。

2.2 PEP 8 命名規格、保留字限制與大小寫敏感性

Python 變數宣告必須遵循官方規範與語法約束：

  • 字元組成限制：僅能包含大小寫英文字母（a-z, A-Z）、數字（0-9）與底線（_）。
  • 開頭字元禁制：識別碼嚴格禁止以數字開頭（例如 1st_token 為非法語法）。
  • 大小寫精確區分（Case-Sensitive）：username、UserName 與 USERNAME 代表符號表中三個完全獨立的鍵。
  • 保留字不可覆蓋（Keywords）：嚴禁使用 Python 內建關鍵字作為變數名稱（如 if, for, class, True, None）。
  • PEP 8 命名慣例：通用變數推薦採用蛇形命名法（snake_case），全小寫字母並以底線分隔單字（例如 server_host）。

2.3 單一賦值、鏈式賦值與多重解構賦值

賦值運算子（=）的執行順序永遠是「先評估等號右側運算式以配置記憶體物件，再將左側識別碼名牌繫結至該位址」。 

# 單一賦值：配置物件並掛上標籤
server_name = "web-prod-01"

# 鏈式賦值：兩個名牌同時繫結至同一個記憶體位址
primary_env = current_env = "production"

# 多重賦值：解構對齊
host_ip, port_num = "192.168.1.1", "8080"

第 3 章：標準輸入機制與 input() 終端互動

3.1 input() 阻塞式讀取機制與提示字串

input() 是 Python 與終端使用者建立雙向互動的標準機制。當直譯器執行至 input() 時，指令指標（Instruction Pointer）將會陷入阻塞狀態（Blocking），程式暫停推進，直到使用者於標準輸入串流（sys.stdin）鍵入字元序列並按下 Enter 鍵發送換行訊號為止。

傳入 input(prompt) 之引數為提示字串，將直接輸出於終端機且不會自動換行，使使用者之鍵盤輸入緊鄰提示文字後方。

3.2 終端輸入之預設純字串（str）本質與特性

鐵律：input() 回傳值永遠是純文字字串（class 'str'）
無論使用者在鍵盤上鍵入何種內容，哪怕全為數字（例如輸入 2026）或布林符號（例如輸入 True），直譯器標準輸入模組一律將其打包封裝為純文字字串物件（即 "2026" 與 "True"），絕不會自動轉換為數值型態。在未定義轉型運算前，嚴禁進行算術運算。 
target_service = input("請輸入欲連接之伺服器名稱: ")
print("已鎖定目標服務：", target_service)

第 4 章：字串資料流整合 —— 串接運算子與 f-string 格式化

4.1 字串串接運算子（+）與不可變物件組合

在 Python 中，加號運算子（+）在運算元皆為字串時，代表字串串接（Concatenation）。

由於 Python 的字串是不可變物件（Immutable），串接運算絕不是在原字串內部追加內容，而是直譯器在堆積記憶體中重新配置一塊全新的記憶體空間，將兩者字元合併後生成全新字串物件。

4.2 現代 f-string 字串插值語法與槽位解析

自 Python 3.6 起導入之格式化字串常值（PEP 498, f-string）是現代 Python 組合資料流的業界標準規範。

  • 語法標記：字串前綴必須緊鄰字母 f 或 F。
  • 動態槽位（Slots）：在大括號 {variable} 內部填入已宣告之變數識別碼。
  • 執行期求值（Runtime Evaluation）：直譯器在執行期解析大括號，主動檢索符號表，將槽位無縫替換為變數內容並組裝為最終字串。
protocol = "HTTPS"
domain = "api.internal.net"

# 方式一：傳統字串串接運算子
endpoint_concat = protocol + "://" + domain

# 方式二：現代 f-string 格式化字串
endpoint_fstring = f"{protocol}://{domain}"

print(endpoint_concat)
print(endpoint_fstring)

第 5 章：單元綜合專案實作與驗證

5.1 實作一：個人基本資料名片輸出程式

任務目標：請宣告個人的「英文姓名」、「職位職稱」與「聯絡信箱」三個字串變數，嚴格遵守 PEP 8 命名規格，並利用現代 f-string 與格式邊框將名片完整印出至終端機中。 

name = "Alex Chen"
