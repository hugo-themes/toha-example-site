01 一、 核心觀念解析

在 Python 直譯器中，數值計算並非單純的文字代入，而是透過運算式（Expression）、運算元（Operand）與運算子（Operator）構成語法樹求值。直譯器在執行算術指令時，嚴格遵循底層資料型態規則與記憶體數值表示法。

1. 運算式與型態提升規則 (Type Promotion)

當不同型態的數值進行算術運算時，Python 直譯器會依據隱式型態轉換（Implicit Type Conversion）法則，自動將精確度較窄的型態（如整數 int）提升至精確度較廣的型態（如浮點數 float），以避免小數資訊在計算過程中遺失：

運算元 A 型態 運算子 運算元 B 型態 求值結果型態 直譯器機制解析
int (5) +, -, * int (2) int 兩整數相加減乘，結果仍為封閉之整數型態。
int (5) / (真除法) int (2) float (2.5) 強制規則：真除法 / 無論能否整除，結果一律為 float。
int (4) / (真除法) int (2) float (2.0) 即使完全整除，亦回傳浮點數 2.0。
int (5) +, -, *, // float (2.0) float 型態提升：整數與浮點數混合運算，結果必定提升為 float。
直譯器視角：為什麼 4 / 2 不是整數 2？

在 Python 3 中，設計者將 / 定義為「真除法（True Division）」，其設計哲學是確保除法運算在數學意義上的連續性與型態穩定性，因此傳回值統一以雙精度浮點數（IEEE 754 float）封裝。

02 二、 基礎語法與範例展示

Python 提供了完整的算術運算子家族，包含四則運算、整數除法與餘數、次方計算，以及簡化賦值操作的複合運算子。

1. 算術運算子規格總覽

運算子 官方名稱 數學意義 程式碼範例 求值結果
+ 加法 (Addition) $a + b$ 3 + 2 5
- 減法 (Subtraction) $a - b$ 5 - 2 3
* 乘法 (Multiplication) $a \times b$ 4 * 2 8
/ 真除法 (True Division) $a \div b$ 9 / 2 4.5
// 地板除法 (Floor Division) $\lfloor a \div b \rfloor$ 9 // 2 4
% 取餘數 (Modulo) $a - (b \times \lfloor a \div b \rfloor)$ 9 % 2 1
** 次方 (Exponentiation) $a^b$ 3 ** 2 9
基礎算術運算標準示範 (arithmetic_basic.py) 
# 基礎四則運算示範
add_result = 3 + 2
sub_result = 5 - 2
mul_result = 4 * 2
div_result = 9 / 2

print(f"3 + 2 = {add_result}")        # 輸出: 5
print(f"5 - 2 = {sub_result}")        # 輸出: 3
print(f"4 * 2 = {mul_result}")        # 輸出: 8
print(f"9 / 2 = {div_result}")        # 輸出: 4.5 (型態為 float)

# 整數商與餘數計算
floor_div = 9 // 2
mod_val = 9 % 2

print(f"9 // 2 (商數) = {floor_div}")  # 輸出: 4
print(f"9 % 2  (餘數) = {mod_val}")    # 輸出: 1

# 次方與開根號 (次方 0.5 等價於平方根)
power_val = 3 ** 2
sqrt_val = 9 ** 0.5

print(f"3 ** 2  = {power_val}")       # 輸出: 9
print(f"9 ** 0.5 = {sqrt_val}")       # 輸出: 3.0

2. 複合賦值運算子 (Augmented Assignment)

複合賦值運算子將「算術運算」與「變數賦值」合而為一。其精神為讀取原變數之值、執行運算後，將新值原地寫回該變數名稱：

複合語法 等價完整語法 執行機制解析
x += 5 x = x + 5 將 x 增加 5 後存回 x
x -= 3 x = x - 3 將 x 減少 3 後存回 x
x *= 2 x = x * 2 將 x 乘以 2 後存回 x
x /= 4 x = x / 4 將 x 除以 4 後存回 x（此時 x 轉為 float）
x //= 2 x = x // 2 將 x 地板除以 2 後存回 x
x %= 3 x = x % 3 將 x 對 3 取餘數後存回 x
x **= 3 x = x ** 3 將 x 計算 3 次方後存回 x

3. 運算子優先順序 (Operator Precedence)

當一個運算式中包含多個運算子時，直譯器依據嚴格的優先等級依序求值。若要打破預設優先順序，必須使用圓括號 () 強制包覆：

優先等級 運算子類別 符號 結合方向 (Associativity)
最高 (Level 1) 括號分組 () 由內而外
Level 2 次方運算 ** 由右至左 (Right-to-Left)（如 2**3**2 = 2**9 = 512）
Level 3 正負號 +x, -x 由右至左
Level 4 乘除家族 *, /, //, % 由左至右 (Left-to-Right)
Level 5 加減家族 +, - 由左至右 (Left-to-Right)
最低 (Level 6) 賦值家族 =, +=, -=, *= ... 由右至左

04 四、 常見陷阱與除錯心法

初學者在進行數值運算時，最常因型態誤解、運算邊界或未轉型導致邏輯錯誤或程式中斷。以下列舉四大必備除錯重點：

1. 陷阱一：除以零引發 ZeroDivisionError

數學上除數不可為零。在 Python 中，無論是真除法 /、地板除法 // 或取餘數 %，只要除數為 0，直譯器均會立即拋出 ZeroDivisionError 例外中斷程式：

錯誤示範 (ZeroDivisionError) 
# 錯誤代碼：除數為 0
total_score = 100
student_count = 0
average = total_score / student_count

# 終端機報錯訊息：
# ZeroDivisionError: division by zero

2. 陷阱二：input() 數值未強制轉型導致字串拼接

在 Lesson 1 中已知 input() 接收的所有輸入一律為字串（str）。若未經 int() 或 float() 轉換即使用 +，直譯器會執行「字串串接（String Concatenation）」而非數值加法：

邏輯錯誤示範 (型態未轉型) 
num1 = input("請輸入第一個數字: ")  # 使用者輸入: 25 -> 得到字串 "25"
num2 = input("請輸入第二個數字: ")  # 使用者輸入: 30 -> 得到字串 "30"

total = num1 + num2
print(f"兩數總和為: {total}")        # 輸出: "2530" (邏輯嚴重錯誤！)

# 正確寫法：使用 int() 或 float() 包覆
correct_total = float(num1) + float(num2)
print(f"正確總和為: {correct_total}") # 輸出: 55.0

3. 陷阱三：浮點數二進位精度微差 (Floating Point Precision)

現代電腦底層使用二進位（IEEE 754）存儲浮點數，某些十進位小數（如 0.1 與 0.2）無法精確化為有限二進位小數，計算時會產生極小微差。在輸出時應善用 f"{val:.2f}" 進行位數格式化：

浮點數精度控制示範 
raw_val = 0.1 + 0.2
print(raw_val)               # 輸出: 0.30000000000000004

# 使用 f-string 格式化控制顯示精確度至小數點後兩位
print(f"格式化輸出: {raw_val:.2f}")  # 輸出: 0.30

05 五、 課堂實作挑戰

以下三道課堂實作題目，緊扣本單元算術運算子、優先順序與 input() 型態轉換，請引導學生於課堂獨立完成。

實作題一：兩數四則運算與商餘綜合計算器

基礎算術驗證

題目需求：請撰寫一支程式，接收使用者輸入的兩個正整數 a 與 b，分別計算並輸出其加、減、乘、真除法、商數（地板除法）、餘數與次方結果。

範例輸入 (stdin)
請輸入第一個整數 a: 9
請輸入第二個整數 b: 2
範例輸出 (stdout)
9 + 2 = 11
9 - 2 = 7
9 * 2 = 18
9 / 2 = 4.5
9 // 2 = 4
9 % 2 = 1
9 ** 2 = 81

實作題二：攝氏溫度轉華氏溫度換算系統

運算優先級應用

題目需求：請撰寫一支程式，讓使用者輸入攝氏溫度（celsius，允許小數），程式將其轉換為華氏溫度（fahrenheit）。轉換公式為：$\text{華氏} = \text{攝氏} \times \frac{9}{5} + 32$。輸出結果需保留小數點後一位。

範例輸入 (stdin)
請輸入攝氏溫度: 25
範例輸出 (stdout)
攝氏 25.0 度 = 華氏 77.0 度

實作題三：BMI 身體質量指數計算器

次方與格式化輸出

題目需求：接收使用者輸入的身高（公分 cm）與體重（公斤 kg）。程式需先將身高換算為公尺（$m = cm / 100$），再依公式計算 BMI：$\text{BMI} = \frac{\text{體重}(kg)}{\text{身高}(m)^2}$。最後使用 f-string 格式化輸出 BMI 數值至小數點後兩位。

範例輸入 (stdin)
請輸入身高 (公分): 175
請輸入體重 (公斤): 68
範例輸出 (stdout)
身高: 175.0 cm | 體重: 68.0 kg
計算所得 BMI 數值為: 22.20
