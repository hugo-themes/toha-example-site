語法錯誤 vs. 執行期例外的本質邊界

維度 語法解析錯誤 (SyntaxError) 執行期例外 (Exception)
發生時機 直譯器將原始碼編譯為位元組碼（Bytecode）的階段。 位元組碼已成功載入，直譯器虛擬機在逐行執行指令時。
直譯器行為 程式碼完全未啟動，連第一行指令都不會執行。 出錯前的程式碼皆已正常執行，直到遇到非法操作瞬間中斷。
能否被攔截 無法在當前檔案內以 try...except 攔截。 可透過結構化語法完全攔截並進行自我修復。

9-2 結構化例外攔截語法：try...except 分支控制

當程式執行可能引發異常的不確定操作時，我們必須設置結構化防護網[cite: 1, 6]。初學者最常產生的盲區是：「以為 try 區塊像資料庫交易一樣，出錯時會自動復原（Rollback）所有改過的變數」[cite: 1, 6]。事實上，Python 是逐行直譯執行的，出錯前已經賦值的變數會永久留在記憶體符號表中[cite: 1, 6]！

9-3 完整防護架構：try...except...else...finally 協同控制流

Python 提供了完整的四段式例外處理控制拓撲，嚴謹地分離「正常推進」、「錯誤修復」與「確定性收尾」三個維度[cite: 1, 6]：

  • try：宣告高風險警戒區，監聽內部是否拋出例外物件[cite: 1, 6]。
  • except：專屬救援維修站，僅在例外發生且型態匹配時觸發[cite: 1, 6]。
  • else：安全放行站，僅在 try 區塊 100% 順暢、毫無任何例外發生時執行[cite: 1, 6]。
  • finally：確定性沖洗艙，無論出錯與否、無論是否命中 except，指令指標必定強制執行[cite: 1, 6]。

9-4 主動防禦與錯誤處理策略對比：自然崩潰 vs. raise 拋出 vs. try 攔截

在現代高可靠度軟體架構中，錯誤處理的三種思維分別扮演著截然不同的系統職責：

維度 1. 放任程式自然崩潰（被動） 2. 主動使用 raise 拋出（進攻型防守） 3. 使用 try...except 攔截（防禦修復）
系統角色 毫無防備的受害者 嚴格把關的品管安檢員 具備備援方案的維修工程師
核心架構思維 聽天由命，任由非法數值污染系統底層，直到崩潰。 快速失敗原則 (Fail-Fast)：在髒資料擴散前主動中斷。 優雅降級 (Graceful Degradation)：吸收已知風險，保障主程序延續。
程式碼職責邊界 未做任何邊界檢查與資料防呆。 模組/函式內部：檢查傳入引數，若不合法則拒絕繼續計算。 呼叫端/外部流程：呼叫高風險功能時，提供後備防護措施。
實務生活情境 ATM 吐出負數鈔票，直到結算日報表失衡引發全面災難。 提款金額小於零時，ATM 立即發出警報並退卡拒絕交易。 用戶在 ATM 插入髒污卡片時，螢幕提示重新操作而非直接死當。

當直譯器拋出未被捕獲的例外時，終端機會印出 Traceback (most recent call last)，這不是程式當機的宣判，而是直譯器留下的現場還原線索[cite: 1, 6]。

實戰任務一：具防呆與例外防護之數值輸入處理

情境需求：設計一個控制台持續輸入的除法計算函式。要求使用者依序輸入被除數與除數，程式必須針對「非法文字輸入（ValueError）」以及「除以零異常（ZeroDivisionError）」提供精確提示並要求重新輸入，直到計算成功產出結果為止[cite: 1, 6]。

pythonrobust_calculator_solution.py
def safe_division_calculator():
    print("=== 數值安全計算機已啟動 ===")
    
    while True:
        try:
            raw_a = input("請輸入被除數 (Numerator)：")
            raw_b = input("請輸入除數 (Denominator)：")
            
            num_a = float(raw_a)
            num_b = float(raw_b)
            result = num_a / num_b

        except ValueError:
            print("【輸入防呆警報】輸入內容包含非數字字元，請重新輸入純數字！\n")
            continue
        except ZeroDivisionError:
            print("【數學運算警報】除數不可為零 (Division by Zero)，請重新指定非零數值！\n")
            continue
        else:
            print(f"✅ 計算成功：{num_a} ÷ {num_b} = {result:.4f}")
            break
        finally:
            print("--- [系統日誌] 該次輸入檢驗週期結束 ---")

# 執行函式
safe_division_calculator()

實戰任務二：串列與字典安全查詢防護函式

情境需求：外部資料結構常出現缺漏。請撰寫兩個安全查詢防護函式：
1. safe_list_get(target_list, index, default)：防止索引越界引發 IndexError。
2. safe_dict_get(target_dict, key, default)：防止鍵不存在引發 KeyError。

pythonsafe_access_helpers.py
def safe_list_get(target_list, index, default=None):
    """
    防禦性存取串列指定索引元素。若索引越界則安全回傳 default 預設值。
    """
    try:
        return target_list[index]
    except IndexError:
        return default

def safe_dict_get(target_dict, key, default=None):
    """
    防禦性存取字典指定鍵。若鍵不存在則安全回傳 default 預設值。
    """
    try:
        return target_dict[key]
    except KeyError:
        return default
