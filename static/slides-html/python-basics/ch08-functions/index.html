8-1 函式宣告、語法定義與呼叫跳轉流程

在電腦科學中，函式是一段被具名封裝的陳述式區塊，其核心目的在於抽象化（Abstraction）與程式碼重用（Code Reuse）。

1. 函式宣告語法原型與 PEP 8 命名規範

Python 透過保留字 def（Define）進行函式宣告。函式名稱遵循蛇形命名法（snake_case），內部程式碼區塊嚴格採用 4 個半形空格縮排。 

# 範例 3：無參數函式定義與直接呼叫
def say_hello():
    print("Hello, World!")

say_hello()

# 範例 4：帶參數函式定義與呼叫
def add(a, b):
    return a + b

add(5, 3)

2. 離散狀態追蹤表：函式宣告與呼叫時序

步驟 (Step) 評估陳述句 指標位置 直譯器底層行為 函式主體是否執行？ 主程式變數狀態
1（定義） def add(a, b): 第 1 行 在記憶體建立函式物件，標記入口位址 否（完全不執行內部，自動略過縮排！） (尚未建立)
2（呼叫） result = add(5, 3) 第 4 行 推進至主程式，看到呼叫運算子 ()，準備跳轉 即將躍入 等待回傳
3（跳轉執行） return a + b 第 2 行 指標實體跳入函式！形式參數接收引數 5 與 3，計算 5 + 3 = 8 是（正式執行運算） 等待回傳
4（回傳賦值） result = 8 回到第 4 行 函式結束退出，將成果 8 交給 result 變數 函式已退場銷毀 result = 8
5（接續推進） print(result) 第 5 行 主程式往下推進，終端機輸出計算結果 — result = 8

8-2 參數設計與引數對齊發射協定

在 Python 中，必須嚴格區分參數與引數：

  • 形式參數（Parameter）：在 def 宣告函式時定義的變數名稱（如 def subtract(a, b): 中的 a 與 b）。
  • 實際引數（Argument）：在呼叫函式時真正傳入的數值或物件（如 subtract(10, 5) 中的 10 與 5）。

常見參數設計型態規格

  • 位置參數（Positional Arguments）：最常見的形式，呼叫端傳入引數的順序必須與定義時完全一致。
  • 關鍵字參數（Keyword Arguments）：呼叫時明確寫出 參數名稱=值，傳入的順序可以隨意對調。
  • 預設參數（Default Arguments）：定義函式時為參數指定預設值。鐵律：有預設值的參數必須排在非預設參數的後方！

多個回傳值本質：元組自動封裝與解構

Python 允許在 return 後面寫多個數值（如 return x, y），直譯器底層實質上是自動將其打包成一個不可變的元組（Tuple），呼叫端可使用多個變數同時解構接收： 

def get_point():
    x = 10
    y = 20
    return x, y  # 底層自動封裝為元組 (10, 20)

# 多變數解構賦值
x_coord, y_coord = get_point()
print(x_coord)  # 10
print(y_coord)  # 20

8-4 變數有效範圍與呼叫堆疊生命週期

函式內部宣告的變數稱為區域變數（Local Variable），僅在函式執行期間存在；外部宣告的為全域變數（Global Variable）。 每次呼叫函式時，直譯器會在呼叫堆疊（Call Stack）上推入（Push）一個專屬的記憶體訊框（Stack Frame），函式執行完畢遇到 return 時，該訊框立即彈出（Pop）並徹底銷毀！

8-6 課堂實作演練

實作題：多功能長方體規格計算機

規格說明：

  1. 設計函式 calculate_box(length, width, height=1)。
  2. 計算底面積（長 × 寬）與總體積（長 × 寬 × 高）。
  3. 以多值回傳方式同時交出：area, volume。
def calculate_box(length, width, height=1):
    area = length * width
    volume = area * height
    return area, volume

# 1. 使用預設高度 (height=1)
base_area, vol1 = calculate_box(5, 4)
print(f"底面積: {base_area}, 體積: {vol1}")

# 2. 關鍵字指定高度
_, vol2 = calculate_box(5, 4, height=3)
print(f"新體積: {vol2}")
