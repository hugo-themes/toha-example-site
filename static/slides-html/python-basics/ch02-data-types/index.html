一、 純量資料型態規格與記憶體模型

Python 直譯器在執行程式時，會依據賦值內容自動推導並在記憶體堆疊（Heap）中配置相對應的物件。Python 屬於「強型別動態語言」（Strongly and Dynamically Typed Language），變數本身僅是持有記憶體參照的「標籤」（Reference），而型態資訊與不可變約束則綁定於實體物件本體上。

1.1 五大純量型態規格矩陣

型態名稱 類型標識 可變性 (Mutability) 典型賦值範例 直譯器儲存本質與限制
整數 (Integer) int 不可變 (Immutable) a = 42, b = -10 任意精度整數（Arbitrary-precision），無 32/64 位元溢位限制。
浮點數 (Float) float 不可變 (Immutable) pi = 3.14159, z = 0.0 遵循 IEEE 754 雙精度標準（64-bit），存在二進位小數微小精度誤差。
布林值 (Boolean) bool 不可變 (Immutable) is_active = True 為 int 的子類別，僅有 True (1) 與 False (0) 兩種單例狀態。
字串 (String) str 不可變 (Immutable) msg = "Python" Unicode 字元有序序列；無法直接透過索引進行就地（in-place）修改。
空值 (NoneType) NoneType 不可變 (Immutable) result = None 表示值不存在或未定義，為全域唯一的單例物件（Singleton）。

1.2 最小可執行範例

# 純量型態定義與 type() 檢驗 age = 25 temperature = -3.5 is_connected = True user_name = "Alice" empty_payload = None print("age type:", type(age)) print("temperature type:", type(temperature)) print("is_connected type:", type(is_connected)) print("user_name type:", type(user_name)) print("empty_payload type:", type(empty_payload))

二、 強制型態轉換機制與規則 (Type Casting)

在處理終端輸入（預設為 str）或跨型態計算時，必須透過型態建構函式進行顯式（Explicit）強制型態轉換。若輸入字串之詞法結構不符合目標型態規格，直譯器將立即中斷並拋出例外。

目標函式 引數合法來源範例 成功轉換結果 引發例外與非法情況
int(x) "42", 3.8, True 42, 3 (無條件捨去小數), 1 int("3.14") 或 int("abc") 拋出 ValueError。
float(x) "3.14", "10", 5 3.14, 10.0, 5.0 float("abc") 或無效字元字串拋出 ValueError。
str(x) 任何物件 (100, 3.14, None) "100", "3.14", "None" 安全無副作用，一律調用物件內部 __str__() 方法。
bool(x) 各型態之值 False 或 True Falsy 純量值：0, 0.0, "" (空字串), None，其餘皆為 True。

三、 字串方法規格與處理管線

字串屬於不可變物件（Immutable Object）。所有字串方法（Method）對字串進行處理時，絕不修改原始字串本體，而是依據運算規則生成一個全新的字串物件並回傳。

3.1 字串核心方法規格矩陣

分類標籤 方法名稱與簽名 回傳型態 功能描述與行為約束
大小寫處理 str.upper() str 回傳所有英文字元皆轉為大寫之新字串。
str.lower() str 回傳所有英文字元皆轉為小寫之新字串。
str.title() str 回傳每個單字首字大寫、其餘小寫之新字串。
搜尋與替換 str.find(sub) int 回傳子字串 sub 首次出現之正向索引；未找到時回傳 -1。
str.replace(old, new) str 將字串中所有 old 子字串替換為 new 並回傳新字串。
修剪與拆分 str.strip() str 移除字串開頭與結尾的所有空白字元（包含 \n, \t, 空格）。
str.split(sep=None) list[str] 依據分隔符 sep 拆分字串並回傳子字串序列。
狀態判定 str.isdigit() bool 若字串非空且所有字元皆為純數字（0-9）則回傳 True。
str.isalpha() bool 若字串非空且所有字元皆為字母則回傳 True。
str.startswith(prefix) bool 檢查字串是否以指定的字首 prefix 開頭。

四、 邊界條件與常見錯誤排查 (Edge Cases & Exceptions)

在轉型與字串操作時，初學者最常因為未預期的資料輸入引發程式中斷崩潰。下表整理常見例外狀況與排查標準：

例外型態 (Exception) 引發錯誤的典型程式碼 直譯器底層原因分析 防範解法與標準修復寫法
ValueError age = int("25.5")
num = int("abc")		 int() 無法將含有小數點或非數字字符的字串直接轉為整數。 先轉為浮點數 int(float("25.5"))，或使用 str.isdigit() 預先檢驗。
TypeError total = "NT$" + 100 Python 嚴格禁止字串（str）與整數（int）直接以 + 運算子串接。 顯式轉型："NT$" + str(100)，或改用 f-string：f"NT${100}"。
AttributeError val = 100
val.strip()		 純量整數 int 型態物件未定義 .strip() 方法。 確認操作物件為字串型態，或先轉型 str(val).strip()。
布林轉型混淆 flag = bool("False")
結果為 True		 非空字串長度大於 0，在真值檢驗中一律判定為 True。 字串內容比對：flag = (input_str == "True")。

五、 課堂實作驗證題 (Hands-on Practice)

實作題 01：使用者註冊資料清洗與規格化工具 基礎字串方法

題目描述：系統從終端接收到使用者輸入的「使用者名稱」與「電子郵件地址」，資料前後可能包含多餘的空白，且大小寫不一致。請撰寫一段程式碼完成資料清洗。

輸入 / 輸出規格 (I/O Spec)：
1. 使用者名稱去除兩端空白後，將每個單字字首轉為大寫（Title Case）。
2. 電子郵件去除兩端空白後，全數轉換為小寫格式（Lower Case）。
3. 依規格格式化輸出清洗後結果。
# 測試資料 (可直接使用變數賦值驗證) raw_username = " alan turing " raw_email = " ALAN.Turing@Example.COM " # --- 請於此處撰寫清洗邏輯 --- clean_username = raw_username.strip().title() clean_email = raw_email.strip().lower() print(f"規格化姓名: '{clean_username}'") print(f"規格化信箱: '{clean_email}'") # [預期輸出] # 規格化姓名: 'Alan Turing' # 規格化信箱: 'alan.turing@example.com'
實作題 02：數值安全檢驗與轉型計算器 型態防禦與轉換

題目描述：從終端接收購買數量字串（例如 " 15 "）與單價字串（例如 "30.5"），請先清除數量兩端的空白，並使用字串方法檢驗數量是否為合法純數字字串。若是，則將數量轉為 int、單價轉為 float，並計算總金額。

輸入 / 輸出規格 (I/O Spec)：
1. 輸出數量之純數字驗證狀態（布林值）。
2. 若驗證成功，輸出總金額（數量 * 單價）。
# 測試輸入 raw_quantity = " 12 " raw_price = "45.0" # --- 清洗與安全驗證 --- cleaned_qty = raw_quantity.strip() is_valid_qty = cleaned_qty.isdigit() print(f"數量字串是否合法: {is_valid_qty}") # 型態轉換與數值運算 qty = int(cleaned_qty) price = float(raw_price) total_amount = qty * price print(f"購買總金額: {total_amount}") # [預期輸出] # 數量字串是否合法: True # 購買總金額: 540.0
