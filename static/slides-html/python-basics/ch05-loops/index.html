一、迭代概念與重複執行機制 (Iteration Fundamentals)

在程式架構中，若需要多次執行相同的運算或輸出任務，手動編寫重複的陳述式會讓程式碼變得冗長且難以維護。直譯器提供了自動重複執行的結構，能根據特定規則或條件，反覆執行同一組程式碼區塊。

💡 觀念聚焦：迴圈與迭代的本質
「迴圈 (Loop)」是指包含重複執行邏輯的程式結構；而每次從資料來源取出一個元素，並完整執行該區塊陳述式的過程，就稱為一次「迭代 (Iteration)」。

Python 提供兩種基本的迴圈語法結構：

  • for 計數迴圈：適合已知迭代次數，或需要依序走訪可迭代物件（Iterable，如字串、串列或整數序列）的情境。
  • while 條件迴圈：適合執行次數不固定，單純依照布林條件式的真假值，來決定是否繼續執行的情境。

二、序列產生器 range() 與 for 計數迴圈走訪

走訪連續整數數列時，通常會搭配內建的 range() 函式。直譯器嚴格遵守「包頭不包尾」（包含起始值、不包含終止值）的邊界規則。例如 range(5) 產生的整數序列為 0, 1, 2, 3, 4。

for i in range(5):
    print(i)
直譯器機制：四段式指令管線與變數標籤綁定模擬器 for 迴圈管線

操作導引：這裡將資料走訪的過程具象化為四段式管線。元素由隊列進入後，會在工位 1 綁定變數識別標籤（i = X），接著平移到工位 2（加工工位）執行 print(i) 並輸出到終端機，最後放行移出。

工位 2：執行 print(i)
工位 1：變數 i 標籤綁定
for i in range(5):
    print(i)

三、前置條件控制：while 迴圈與終止條件設計

while 屬於前置條件控制結構。直譯器在每次進入迴圈主體前，都會先評估條件式的布林值：若為 True 就放行進入；執行完區塊最後一行陳述式後，控制流程會折返回開頭重新評估；一旦條件結果為 False，就會終止迴圈並離開結構。

count = 0
while count < 5:
    print(f"計數：{count}")
    count += 1
⚠️ 常見邏輯錯誤：無窮迴圈（Infinite Loop）
若迴圈主體內漏寫了 count += 1 這類推進狀態的陳述式，count 會恆為 0，導致 count < 5 永遠是 True。直譯器將無法脫離這個結構，造成程式卡死無法停止。撰寫 while 迴圈時，務必確保內部有讓條件趨向 False 的變更邏輯。
直譯器機制：前置條件評估、狀態推進與流程折返模擬器 while 迴圈環道
條件檢驗：while count < 5
處理工位：print(count)
狀態推進：count += 1

四、流程中斷控制：break、continue 與 pass 陳述式

在迴圈迭代的過程中，可以使用流程跳躍關鍵字來改變預設的執行順序：

  • break（強制中斷）：立即終止目前所在的迴圈結構，直接跳出並執行後續的程式碼。後續還沒走訪的元素會全數拋棄，不再處理。
  • continue（略過當次）：立即略過本次迭代 continue 後面的剩餘程式碼。直譯器不會終止迴圈，而是直接折返回開頭，呼叫下一個元素進入下一輪迭代。
  • pass（空操作佔位）：單純用來填補語法結構需要的位置，直譯器不會執行任何動作，通常用在構思程式框架時作為結構佔位符。

五、多維資料處理：雙層巢狀迴圈結構 (Nested Loops)

當一個迴圈結構內部又包含了另一個迴圈時，就稱為「巢狀迴圈 (Nested Loops)」。外層指標每前進 1 步，內層迴圈就必須完整執行完它定義的所有迭代週期。

💡 運作模型：時鐘齒輪運作比
外層迴圈就像「時針」，內層迴圈就像「分針」。外層指針每前進 1 個刻度，內層指針就會完整走完一整圈。這種架構常用於多維資料結構、矩陣運算與二維網格排版。 
for i in range(1, 4):
    for j in range(1, 4):
        product = i * j
        print(f"{i}x{j}={product}", end="  ")
    print()
直譯器機制：雙軸維度走訪與二維矩陣時序掃描儀 巢狀迴圈掃描
