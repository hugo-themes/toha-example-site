第一章：比較運算子與布林值判定

在進入程式的分支決策之前，電腦必須具備衡量與辨明真偽的能力。在 Python 中，所有比較運算本質上就像是一座精密的天秤：天秤兩端放置資料，檢測完畢後，只會產生兩種不可撼動的布林值（Boolean）結果：True（真）或是 False（假）。這種布林狀態，正是所有控制流程決策的基礎。

1-1 數值衡量：認識 6 大比較運算子

Python 提供了 6 種最基礎的比較運算子，用於數值與資料內容的比對：

pythoncomparison_demo.py
score = 85

print(score > 60)
print(score < 50)
print(score >= 85)
print(score <= 80)
print(score == 85)
print(score != 100)

1-2 觀念避坑：指定值「=」與 數值比較「==」的本質差異

⚠️ 零基礎避坑提醒：
初學者極常將數學上的「等於」習慣寫成單一個等號 =。
請在課堂上為學生建立嚴謹的心智模型：
  • 單等號 =（賦值 Binding）：是「繫上名牌吊牌」，將變數名稱綁定到右側物件。
  • 雙等號 ==（比較 Comparison）：是「拿出天秤比對」，詢問直譯器左右兩側的值是否相等。
如果在條件式中誤寫為 if x = 5:，直譯器會立即拋出 SyntaxError: invalid syntax 語法錯誤！

第二章：邏輯運算子與短路求值

日常生活中，事件的發生往往取決於多項條件的組合。在 Python 中，我們使用三大邏輯運算子：and（且）、or（或）、not（非）。

2-1 多重條件檢查：真值表與邏輯法則

條件 A 運算子 條件 B 計算結果 邏輯法則
True and True True 雙方皆為 True，結果才為 True
True and False False 任一方為 False，結果即為 False
True or False True 任一方為 True，結果即為 True
False or False False 雙方皆為 False，結果才為 False
True not — False 邏輯反轉，反轉真假狀態

2-2 直譯器求值機制：短路求值（Short-circuit Evaluation）

直譯器在運算複合邏輯時非常講究執行效率。若左側運算式的結果已經足以決定最終的布林值，直譯器就會直接中斷，跳過右側運算式的求值程序！這種機制稱為「短路求值」。

動態教具一：邏輯審查機器人——短路求值模擬器 (短路求值路徑可視化)

[SYS_READY] 邏輯審查單元待命中。
【右側運算元 B】
True
⚡ 短路中斷 (Skipped) 直譯器終止後續求值

第三章：條件分支控制結構（if / elif / else）

掌握了真偽判斷後，我們就能指引 Python 走向不同的程式區塊。Python 的條件分支結構就像是鐵道上的轉轍器，負責引導載運資料的指令指標（IP）駛入指定的程式碼區塊。

3-1 單向通行閘門：if 條件式

只有滿足條件時，才會執行特定動作；若不滿足，則會直接繞過該區塊：

pythonsingle_if.py
age = 18

if age >= 18:
    print("你已經成年")

3-2 雙向分流：if...else 結構

非此即彼，兩個區塊必定擇一執行，絕不可能同時跳過或同時執行：

pythonif_else.py
age = 16

if age >= 18:
    print("你已經成年")
else:
    print("你還未成年")

3-3 多向條件分支：if...elif...else 互斥階梯與順序依賴

當面臨 3 種以上的分流需求時，使用 elif（即 else if 之縮寫）。請務必向學生強調：這是一座由上而下的互斥階梯，一旦上方條件成立，整個判斷流程就會直接結束，下方所有的 elif 與 else 都會被指令指標略過（Bypass）！

第四章：條件判斷進階技巧與複合邏輯

4-1 單行條件運算式（三元運算子）

當只有單純的二選一賦值需求時，Python 支援將 if-else 撰寫為精巧的一行表達式：

變數 = 真實結果 if 判斷條件 else 虛假結果

pythonternary_demo.py
is_adult = True
status = "成人" if is_adult else "未成年"
print(status)

4-2 複合條件判斷：邏輯運算子與分支整合

我們可以使用括號與邏輯運算子組合多個條件，設立多重檢驗門檻：

pythoncombined_conditions.py
temperature = 30
weather = "晴天"

if temperature > 25 and weather == "晴天":
    print("天氣很好，適合外出")
else:
    print("天氣不太好")

第五章：新手常見語法陷阱與除錯指南

5-1 縮排（Indentation）結構：空白字元的區塊界定

在 Python 中，直譯器完全依賴「空白縮排」來辨識程式碼的區塊層級！

pythonindentation_error.py
# 錯誤示範：忘記縮排
if 5 > 3:
print("這行會直接拋出 IndentationError！")

# 正確規範：縮排統一使用 4 個半形空白，切勿混用 Tab 鍵

5-2 語法標點：忘記冒號「:」的常見錯誤訊息

if、elif、else 行尾的冒號代表「提示直譯器：接下來將進入子區塊」。漏掉冒號會立即引發 SyntaxError: expected ':' 語法錯誤。

第六章：課堂實戰任務挑戰

任務一：判斷正負數與零

規則說明：撰寫程式，根據使用者輸入的整數判斷其為正數、負數還是零。

pythonnumber_sign_solution.py
num = int(input("請輸入一個數字："))

if num > 0:
    print("這是一個正數")
elif num < 0:
    print("這是一個負數")
else:
    print("這是零")

任務二：公曆閏年判定系統

規則說明：公曆閏年規則如下：能被 4 整除且「不能被 100 整除」，或能被 400 整除者為閏年，其餘為平年。

pythonleap_year_solution.py
year = int(input("請輸入年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是閏年")
else:
    print(f"{year} 不是閏年")

任務三：成績分級系統

規則說明：根據使用者輸入的成績（0~100），輸出對應的等級（A, B, C, D, F）。

pythonscore_evaluator_solution.py
score = int(input("請輸入成績："))

if score >= 90:
    print("等級 A")
elif score >= 80:
    print("等級 B")
elif score >= 70:
    print("等級 C")
