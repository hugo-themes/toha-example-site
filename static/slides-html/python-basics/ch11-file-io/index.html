11-1 檔案系統抽象化與物件導向路徑操作：pathlib 模組

在傳統 Python 程式碼中，檔案路徑多以純字串（str）進行處理。此作法極易在跨作業系統部署時引發路徑分隔符號衝突（POSIX 系統使用正斜線 /，Windows 系統使用反斜線 \）。自 Python 3.4 起引入的 pathlib 模組，將檔案系統抽象化為純物件導向語意，具備跨平台語法安全與鏈式操作能力。

11-1.1 pathlib.Path 物件實例化與除法運算子重載

pathlib.Path 類別重載了 Python 的除法運算子（/），使得路徑層級的串接能以直觀且平台無關的語法完成：

操作面向 傳統 os.path 語法 現代 pathlib 物件導向語法 底層運作與回傳型態
取得目前工作目錄 os.getcwd() Path.cwd() 回傳當前目錄之 Path 實例。
路徑安全串接 os.path.join(a, b) base_path / "data" / "file.txt" 呼叫 __truediv__() 進行路徑拼接。
絕對路徑解析 os.path.abspath(path) path.resolve() 解析符號連結並輸出標準絕對路徑。

11-1.2 路徑核心屬性存取與檔案狀態檢驗

Path 物件提供多項唯讀屬性存取路徑組成元件，並內建檔案系統狀態檢驗方法：

  • .name：取得完整檔案名稱（包含副檔名，例如 "report.csv"）。
  • .stem：取得檔案主檔名（排除副檔名，例如 "report"）。
  • .suffix：取得副檔名標記（例如 ".csv"）。
  • .parent：取得上一層父目錄物件，支援鏈式存取（例如 path.parent.parent）。
  • .exists()：檢查實體磁碟是否存在此路徑（回傳布林值）。
  • .is_file() / .is_dir()：判定路徑是否為常規檔案或目錄。
  • .glob(pattern)：依據萬用字元（如 "*.json"）搜尋目錄下符合之檔案集合。

標準示範程式碼（嚴格 PEP 8 換行）

from pathlib import Path

# 1. 建立基礎工作路徑
base_dir = Path.cwd()
target_file = base_dir / "workspace" / "metadata.json"

# 2. 物件導向屬性存取
print(f"完整路徑: {target_file}")
print(f"檔案全名: {target_file.name}")
print(f"檔案主名: {target_file.stem}")
print(f"副檔名: {target_file.suffix}")
print(f"父層目錄: {target_file.parent}")
print(f"實體是否存在: {target_file.exists()}")

11-2 上下文管理器與文字檔案基礎 I/O：with open()

檔案存取牽涉作業系統底層核心資源。當 Python 程式調用 open() 時，作業系統核心會配置一個檔案描述子（File Descriptor, FD）。若未顯式釋放，可能導致資源洩漏、檔案鎖定或快取寫入延遲。

11-2.1 with 陳述式運作協議與資源保護機制

傳統使用 file.close() 的寫法，若在讀寫過程中發生例外崩潰，關閉指令將被略過。with 陳述式導入了上下文管理器協議（Context Management Protocol）：

  • 進入區塊時：自動觸發物件的 __enter__() 方法，回傳已開啟的串流物件並繫結至 as 變數。
  • 離開區塊時：無論是正常執行完畢，或區塊內部突發嚴重例外（如 ValueError、ZeroDivisionError），直譯器保證強制調用 __exit__()，釋放底層檔案描述子。

11-2.2 串流讀取方法與搬運模式演繹 (.read, .readline, .readlines)

Python 提供多種從檔案串流抽取資料的方法，不同方法在記憶體結構與返回型態上有本質差異：

  • file.readline()：單行公文夾提取。每次呼叫僅搬運單一行文字列並存入變數，指標停在下一行開頭。再次呼叫則搬運下一行。
  • file.readlines()：串列分格置物箱打包。搬運工攜帶一個具備索引格位的置物箱（串列 list），逐行抽取並將每一行獨立放入不同格位，一次性返回 list[str]。
  • file.read()：連續文字長卷軸直接載入。將整個檔案的所有字元不分行全數捲成單一長字串（str）。大檔案嚴禁使用以防記憶體耗盡。

11-2.3 檔案開啟模式語意拓撲：'r', 'w', 'a'

模式字元 語意行為 檔案不存在時 檔案已存在時
'r' (唯讀) 僅允許讀取資料串流（預設模式）。 拋出 FileNotFoundError。 保持原內容不變，指標置於開頭。
'w' (寫入覆蓋) 僅允許寫入資料串流。 自動建立全新實體檔案。 立即截斷清空檔案內容（Truncate 歸零）。
'a' (尾端附加) 僅允許由尾端寫入資料串流。 自動建立全新實體檔案。 指標自動鎖定在檔案尾端，原內容完好。
'x' (獨佔建立) 防禦性建立並寫入檔案。 建立全新實體檔案。 直接拋出 FileExistsError 拒絕覆蓋。

標準示範程式碼（嚴格 PEP 8 換行）

from pathlib import Path

file_path = Path("demo.txt")

# 1. 安全覆蓋寫入文字檔
with open(file_path, mode="w", encoding="utf-8") as file:
    file.write("Python 資料工程\n")
    file.write("現代 File I/O 實務\n")

# 2. 原生檔案迭代器逐行走訪
with open(file_path, mode="r", encoding="utf-8") as file:
    for line in file:
        clean_line = line.strip()
        print(f"讀取內容: {clean_line}")

# 離開 with 區塊後自動關閉檢驗
print(f"檔案是否已安全關閉: {file.closed}")

11-3 表格資料結構化交換：csv 模組

逗號分隔值（Comma-Separated Values, CSV）為表格資料交換的主流文字格式。由於資料內容可能包含半形逗號、引號或換行字元，若使用純字串方法 .split(",") 進行剖析，將引發嚴重的欄位錯位崩潰。Python 內建的 csv 模組完整實作了 RFC 4180 規格，能精確處理逸出字元與文字包裹規則。

11-3.1 串列型介面 vs 字典型介面規格

處理維度 串列型介面 (reader / writer) 字典型介面 (DictReader / DictWriter)
每列資料結構 純字串串列：list[str] 以標頭為鍵的字典：dict[str, str]
標頭行處理 需手動調用 next(reader) 提取或跳過標頭。 自動將第一列解析為字典欄位鍵（Keys）。
欄位順序依賴性 高度依賴索引位置（例如 row[0], row[1]）。 依據欄位名稱存取（例如 row["price"]），程式碼彈性高。
寫入標頭需求 手動呼叫 writer.writerow(header_list)。 建立時指定 fieldnames，調用 writer.writeheader()。

newline='' 參數關鍵約束：在呼叫 open() 開啟檔案以供 csv.writer 寫入時，必須嚴格傳入 newline='' 參數。若未宣告此設定，Python 的通用換行模組與 csv 內部換行控制將在 Windows 平臺上重疊疊加，導致輸出的 CSV 檔案每筆資料列之間皆產生額外的空白行。

標準示範程式碼（嚴格 PEP 8 換行）

import csv
from pathlib import Path

csv_path = Path("inventory.csv")
products = [
    {"sku": "A101", "name": "機械鍵盤", "price": 2800, "stock": 45},
    {"sku": "B202", "name": "無線滑鼠", "price": 1200, "stock": 80},
    {"sku": "C303", "name": "螢幕支架", "price": 1500, "stock": 15}
]

# 1. 字典型介面寫入 (務必加上 newline='')
field_names = ["sku", "name", "price", "stock"]
with open(csv_path, mode="w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=field_names)
    writer.writeheader()
    writer.writerows(products)

# 2. 字典型介面讀取與結構化運算
with open(csv_path, mode="r", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    for row in reader:
        # 注意：CSV 讀入的值一律為字串，需顯式轉型
        total_val = int(row["price"]) * int(row["stock"])
        print(f"品項: {row['name']} | 庫存總值: {total_val}")

11-4 輕量資料序列化協定：json 模組

JavaScript 物件標記法（JavaScript Object Notation, JSON）為現代分散式系統、微服務與 Web API 資料交換的工業標準。JSON 為純文字格式，但具有嚴格的結構階層。json 模組負責 Python 記憶體物件與 JSON 文字串流間的序列化（Serialization）與反序列化（Deserialization）。

11-4.2 核心方法區隔：s 字尾之記憶體字串 vs 檔案資料流

  • 記憶體字串轉換（含 s 結尾）：
    • json.dumps(obj)：將 Python 物件序列化為 JSON 格式純字串（str）。
    • json.loads(json_str)：將 JSON 格式純字串 解析反序列化為 Python 記憶體物件。
  • 實體檔案串流操作（無 s 結尾）：
    • json.dump(obj, file_stream)：將 Python 物件直接序列化並寫入已開啟的檔案串流。
    • json.load(file_stream)：從已開啟的檔案串流直接讀取文字並反序列化為 Python 物件。

標準示範程式碼（嚴格 PEP 8 換行）

import json
from pathlib import Path

config_data = {
    "app_name": "監控服務器",
    "port": 8080,
    "enable_ssl": True,
    "cluster_nodes": ["node-a", "node-b"],
    "proxy_route": None
}

json_file = Path("app_config.json")

# 1. 檔案串流寫入 (包含縮排與繁體中文保留)
with open(json_file, mode="w", encoding="utf-8") as file:
    json.dump(config_data, file, indent=2, ensure_ascii=False)

# 2. 檔案串流讀取反序列化
with open(json_file, mode="r", encoding="utf-8") as file:
    loaded_config = json.load(file)

print("反序列化完成，型態為:", type(loaded_config))
print(f"服務名稱: {loaded_config['app_name']}")
print(f"SSL 狀態: {loaded_config['enable_ssl']} (原生布林值: {isinstance(loaded_config['enable_ssl'], bool)})")

11-6 課堂綜合實作驗證題

實作題 01：電商會員資料 CSV 匯入、欄位格式清洗與條件過濾導出工具 CSV & Pathlib

題目描述：系統從前臺匯出了一份名為 raw_members.csv 的名冊，部分使用者的消費金額帶有小數點，且狀態欄位大小寫不一。請使用 pathlib.Path 與 csv.DictReader 讀取檔案，篩選出狀態為有效會員（狀態不區分大小寫為 "active"）且累計消費大於等於 1,000 元的使用者，最後使用 csv.DictWriter 將清洗後名單寫入新檔案 filtered_vip.csv。

輸入 / 輸出規格 (I/O Spec)：
1. 來源欄位包含：uid, name, total_spend, status。
2. total_spend 須轉換為浮點數比較後，輸出四捨五入為整數。
3. 輸出新檔案時，欄位順序維持不變，且必須確保在 Windows 平臺無空行產生。

參考實作程式碼： 

import csv
from pathlib import Path

input_path = Path("raw_members.csv")
output_path = Path("filtered_vip.csv")

# 1. 建立測試用原始資料
raw_data = [
    {"uid": "U1001", "name": "林小明", "total_spend": "1500.5", "status": "ACTIVE"},
    {"uid": "U1002", "name": "陳大華", "total_spend": "800.0", "status": "active"},
    {"uid": "U1003", "name": "張美麗", "total_spend": "3200", "status": "suspended"},
    {"uid": "U1004", "name": "王國榮", "total_spend": "2400", "status": "Active"}
]

fieldnames = ["uid", "name", "total_spend", "status"]

with open(input_path, mode="w", encoding="utf-8", newline="") as f:
    w = csv.DictWriter(f, fieldnames=fieldnames)
    w.writeheader()
    w.writerows(raw_data)

# 2. 資料清洗與篩選邏輯
valid_vips = []
with open(input_path, mode="r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        spend = float(row["total_spend"])
        status = row["status"].strip().lower()
        if status == "active" and spend >= 1000.0:
            valid_vips.append({
                "uid": row["uid"],
                "name": row["name"],
                "total_spend": str(round(spend)),
                "status": "Active"
            })

# 3. 匯出過濾結果 (嚴格指定 newline='')
with open(output_path, mode="w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(valid_vips)

print(f"篩選完成，共匯出 {len(valid_vips)} 筆 VIP 會員資料。")
實作題 02：系統環境組態設定檔 JSON 讀寫、版本驗證與自動備份器 JSON & 容錯防護

題目描述：請撰寫一段維運指令碼，使用 pathlib.Path 檢查當前目錄下是否存在組態設定檔 config.json。若存在，則讀取其內容並將版本號碼（version）遞增 0.1，並在磁碟中複製產生一份檔名為 config.backup.json 的備份檔；若檔案不存在，則動態建立一份標準初始組態檔並儲存。

輸入 / 輸出規格 (I/O Spec)：
1. 初始設定資料包含：app_id, version, debug_mode, endpoints。
2. 輸出時必須啟用縮排格式化（indent=2）與非 ASCII 字元保護（ensure_ascii=False）。
3. 嚴格使用上下文管理器 with open() 確保讀寫完畢後檔案立即安全關閉。

參考實作程式碼： 

import json
from pathlib import Path

config_path = Path("config.json")
backup_path = Path("config.backup.json")

# 檢查檔案狀態
if not config_path.exists():
    initial_config = {
        "app_id": "payment_service",
        "version": 1.0,
        "debug_mode": False,
        "endpoints": ["https://api.domain.com/v1"]
    }
    with open(config_path, mode="w", encoding="utf-8") as f:
        json.dump(initial_config, f, indent=2, ensure_ascii=False)
    print("組態檔不存在，已建立標準預設設定檔。")
else:
    with open(config_path, mode="r", encoding="utf-8") as f:
        current_config = json.load(f)

    # 1. 建立備份檔
    with open(backup_path, mode="w", encoding="utf-8") as f:
        json.dump(current_config, f, indent=2, ensure_ascii=False)

    # 2. 更新原設定檔版本號碼
    current_config["version"] = round(current_config["version"] + 0.1, 1)
    with open(config_path, mode="w", encoding="utf-8") as f:
        json.dump(current_config, f, indent=2, ensure_ascii=False)
